# 3.19.5 → 3.19.8

对照文件：`BNApp64_V3.19.5.apk`（293.59 MB，universal + 73 个 arm64 so）→ `币安 3.19.8.apk`（251.98 MB，**无 lib/**，像 Play base 拆分）。

权限：去掉 `REQUEST_INSTALL_PACKAGES`。内置小程序还是 3 个，Flutter package 14 个没变。DEX 27 → 23，全量 CRC 变了，按组件看不是重写。
