# 3.19.5 → 3.19.8

对照文件：`BNApp64_V3.19.5.apk`（293.59 MB）→ **`BNApp64_V3.19.8.apk`**（294.80 MB，universal，74 个 arm64 so）。

同目录还有 `币安 3.19.8.apk`（251.98 MB，Play base，0 个 so，arsc 7.5 MB）。那份只说明包装，**不要拿来当产品删了 native / 中文**。

权限：完整包相对 3.19.5 **无增减**。Play base 的 Manifest 去掉了 `REQUEST_INSTALL_PACKAGES`，以 universal 为准。  
内置小程序还是 3 个，Flutter package 14 个没变。DEX 仍 27，全量 CRC 变了，按组件看不是重写。
