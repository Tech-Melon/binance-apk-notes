# 3.19.8 → 3.20.1

对照文件：`币安 3.19.8.apk`（251.98 MB，Play base）→ **`币安 3.20.1.apk`**（254.40 MB，Play base，0 个 so，arsc 7.27 MB）。

**没有 3.20.1 的 `BNApp64`。** 完整 3.19.8（`BNApp64_V3.19.8.apk`，294.80 MB，74 个 so）只用来做文案归属，不当这一轮的包装差集。缺 so / 缺中文 / Manifest 没有 `REQUEST_INSTALL_PACKAGES` **都是 Play base 包装**，3.19.8 已经踩过。

权限：相对 3.19.8 Play base **无增减**。  
内置小程序还是 3 个 id。Flutter package 14 → **15**。DEX 23 → 24。
