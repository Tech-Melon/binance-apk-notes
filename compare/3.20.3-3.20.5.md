# 3.20.3 → 3.20.5

对照文件：`币安 3.20.3.apk`（262.03 MB，Play base）→ **`币安 3.20.5.apk`**（262.83 MB，Play base，0 个 so，arsc 7.41 MB）。

**没有 3.20.5 的 `BNApp64`。** 完整 3.19.8（`BNApp64_V3.19.8.apk`）只用来做文案归属，不当这一轮的包装差集。缺 so / 缺中文 / Manifest 没有 `REQUEST_INSTALL_PACKAGES` **都是 Play base 包装**，3.19.8 / 3.20.1 / 3.20.3 已经踩过。

权限：相对 3.20.3 Play base **无增减**。  
内置小程序还是 3 个 id。Flutter package 仍 15。DEX 仍 24。小程序运行时仍 5.16.4。
