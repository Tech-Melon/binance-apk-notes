# 3.20.5 → 3.20.6

对照文件：`币安 3.20.5.apk`（262.83 MB，Play base，0 个 so，arsc 7.41 MB）→ **`BNApp64 (2).apk`**（306.82 MB，universal，76 个 arm64 so，arsc 83.47 MB）。

**这是 3.19.8 之后第一份完整包。** 3.20.5 没有 `BNApp64`。两边不能把 so、中文、`REQUEST_INSTALL_PACKAGES` 当成产品差。完整 3.19.8 用来做文案归属和 so 文件名对照；so 差值跨过 3.20.1–3.20.5。

权限：相对完整 3.19.8 **无增减**（都是 47，含 `REQUEST_INSTALL_PACKAGES`）。相对 3.20.5 Play base 多了这一条，是包装。  
内置小程序还是 3 个 id。Flutter package 相对 3.20.5 仍 15。小程序运行时仍 5.16.4。DEX 24 → 28。
